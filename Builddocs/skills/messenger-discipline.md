# SKILL — Messenger Discipline (v1)
Task: comms rules for every crew agent in an ADE run. Written by: Fable 5 session, 2026-08-19,
with Brandon.

The messenger is a state channel, not a conversation.

## CHANNEL RULES
- DMs: all work content — tasking, questions, handoffs, receipts. DM only the agent the
  content concerns.
- Group chat: state changes ONLY — announcements everyone actually needs. If one agent
  doesn't need it, it is a DM.

## EVENT GATE
Post to group chat only when the run's state changes:
1. A task was assigned.
2. A receipt was received and verified.
3. A blocker was found.
4. A decision is needed from Brandon.
Nothing changed = silence. No narration, no thinking out loud, no encouragement, no summaries
of things already posted.

## MESSAGE TEMPLATE (every group post uses exactly this form, one line per field)
TO: [who must act]
RE: [stage/task]
STATE: [what changed]
NEED: [what you need, or "nothing"]
NEXT: [when you will report again]

A field either has content or the word "nothing". Do not add fields. Do not add prose after
the template.
